# Localization (i18n) Keys

Five equal first-class languages: English, German, Turkish, Arabic, Russian.

## Architecture

```
shared/i18n/admin_texts.json                         <- canonical single source
  381 keys x 5 languages (en, de, tr, ar, ru)
        |
        v (generated)
cloudflare-worker/src/i18n/admin-shared.generated.js <- generated by scripts/generate_admin_i18n.mjs
        |
        v (mirrored by hand, same key set)
apps/admin-android/.../ui/AdminSharedTexts.kt        <- AdminSharedTexts / t(key)
apple/shared/Sources/AdminSharedTexts.swift          <- AdminSharedTexts (identical layout)
```

Verification source: `shared/i18n/admin_texts.json`, `cloudflare-worker/src/i18n/admin-shared.generated.js:1`, Android `AdminSharedTexts.kt`, iOS `AdminSharedTexts.swift`.

## Rules

1. Every new or changed user-facing/admin-facing text key is added in **all five languages** in `shared/i18n/admin_texts.json`.
2. The generated file is regenerated from the JSON source.
3. Android and iOS mirrored dictionaries are updated with the same key set (do not leave any language structurally missing).
4. Keys are `snake_case` English strings.
5. Arabic text is rendered RTL in UI; it must not be structurally second-class.
6. No language-specific fallback exceptions unless technically required.
