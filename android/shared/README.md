# Shared Android Module

Shared code for Admin App and Customer App.

Responsibilities:

- API client
- DTO models
- auth/session handling
- secure token storage abstraction
- language/i18n definitions
- order status formatting
- price formatting
- date formatting
- reusable UI components
- design tokens
- error/loading/empty state models
- RTL readiness helpers
